# BUYORNOT 마이페이지 구성안

오른쪽 상단 내 계정에서 진입하는 개인 활동 관리 화면. 큐레이션 룸과 추후 살말 투표를 함께 관리한다.

## 화면 구조

1. 프로필: 닉네임, 프로필 이미지, 프로필 수정. 로그인 방식은 내 정보 관리에 표시한다.
2. 활동 요약: 내가 쓴 글, 참여한 투표, 저장한 상품. 클릭하면 해당 목록으로 이동한다.
3. 최근 활동: 최근 작성 글과 새로 도착한 답변·투표 종료 알림.
4. 메뉴: 마이페이지 홈 / 내가 쓴 글 / 참여한 투표 / 저장한 상품 / 알림 / 내 정보 관리.

## 기능과 버튼

| 영역                | 표시할 내용                                                            | 버튼·동작                                                   |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------- |
| 내가 쓴 글          | 전체 / 큐레이션 질문 / 살말 투표 탭, 상품 사진·상품명·가격·작성일·상태 | 검색, 최신순 정렬, 글 상세, 수정, 삭제                      |
| 큐레이션 질문       | 크리에이터 이름, 답변 대기 / 답변 완료 / 만료, BUY·NOT 답변            | 답변 보기, 큐레이션 룸 보기, 상품 보러 가기                 |
| 내가 만든 살말 투표 | 진행 중 / 종료, 참여 인원, 종료일, BUY·NOT 결과                        | 투표 상세, 결과 보기, 상품 보러 가기                        |

| 알림                | 크리에이터 답변 도착, 내 투표 종료                                     | 해당 글 보기, 읽음 처리, 모두 읽음                          |
| 내 정보 관리        | 닉네임·프로필, 로그인 방식, 이메일                                     | 프로필 저장, 이메일 계정 비밀번호 변경, 로그아웃, 회원 탈퇴 |

## 글 작성 진입

공통 ‘글 작성’ 버튼에서 ‘크리에이터에게 질문하기’와 ‘살말 투표 만들기’를 선택한다. 큐레이션 질문은 룸 선택 후 작성하고, 살말 투표는 상품·질문·마감일을 입력한다. 아직 투표가 구현되지 않은 현재 화면에는 작동하는 것처럼 노출하지 않는다.

## 표시 원칙

- 큐레이션 카드에는 크리에이터의 답변과 상태를 표시하고 투표율 막대는 표시하지 않는다.
- 투표 카드에는 참여 인원과 결과를 표시한다. 결과 공개 시점과 투표 변경 허용 여부는 투표 기능 구현 전에 결정한다.
- 상품 이미지는 실제 상품 대표 사진을 비율 유지해 표시한다. 실패 시 안내를 표시하며 다른 상품 사진으로 대체하지 않는다.
- 사진·상품 링크와 게시글 상세 링크를 구분한다. 목록에서 수정·삭제는 본인 글에만 제공하고 기존 권한 정책을 적용한다.
- 빈 목록, 불러오기 실패·재시도, 저장 중, 삭제 확인 상태를 제공한다.
- 회원 탈퇴는 데이터 처리 범위를 안내하고 별도 확인 후 처리한다.
- 주문·배송·쿠폰은 외부 쇼핑몰에서 구매하는 서비스 구조이므로 넣지 않는다.

## 구현 현황과 순서

현재 연결됨: 인증된 계정의 큐레이션 질문 목록·상태별 필터·검색, 작성·수정·삭제, 닉네임 변경, 로그아웃.

이번 수정: 상품 썸네일 컨테이너에 위치 기준을 지정해 내부의 absolute 이미지가 카드 밖으로 벗어나지 않도록 수정.

다음 구현: 살말 투표 저장소와 권한·집계 → 내가 쓴 글의 유형별 탭 및 참여 내역 → 저장한 상품 → 답변·종료 알림 → 프로필 이미지·회원 탈퇴. 현재 없는 기능의 수치를 임의로 표시하지 않는다.

## 통합 마이페이지 화면 적용

- 홈에 커뮤니티·큐레이션 진입 카드와 전체 활동 요약을 배치했다.
- 내가 쓴 글에 전체 / 살말 커뮤니티 / 큐레이션 질문 유형 탭을 추가했다.
- 내 참여 내역(투표·댓글·댓글 단 글), 저장한 글·상품, 팔로우한 크리에이터, 알림 화면을 추가했다.
- 글 작성은 유형 선택 모달을 거치며 현재 연결된 큐레이션 질문 작성만 활성화한다.
- 커뮤니티·투표·댓글·저장·팔로우·알림 저장소는 현재 저장소에 없어 연결 준비 중 화면을 제공한다. 이를 실제 0건 기록처럼 표시하지 않는다. 프로필 이미지 업로드와 탈퇴·알림 설정은 아직 구현하지 않았다.

## 여러 큐레이션 룸 예시 연결

로컬 일반회원 테스트 계정에 가상 크리에이터 7명(나윤·유리·리온·모아·하린·서우·도아)을 팔로우한 예시를 저장했다. 실제 인증 계정은 생성하지 않았으며 공개된 실제 인물 정보나 사진을 사용하지 않았다. 프로필과 배너는 로컬 SVG 그래픽이다.

기존 소올 룸을 유지하고 예시 질문 32개를 8개 룸에 4개씩 배치했다. 질문 카드에 크리에이터 프로필·이름·룸 이동 링크를 표시하고 크리에이터별 필터와 질문 작성 시 룸 선택을 추가했다. 팔로우 해제 후에도 기존 질문은 유지되며 다시 팔로우할 수 있다. 이 예시 룸과 팔로우 데이터는 `.local-test-accounts/activity.json`에 보관된다.

## 크리에이터 콘텐츠 메뉴 정리

크리에이터 피드를 삭제하고 큐레이션 룸과 추천 숍만 유지한다. 답변 대기·BUY·NOT·만료는 큐레이션 룸에서 확인하고, 추천 숍은 BUY 판정 상품만 모아 보여준다. 기존 `view=feed` 주소는 큐레이션 룸으로 해석한다. 기존 질문·답변·상품 데이터는 유지한다.

## 비공개 신체 정보와 작성창 불러오기

계정 설정에서 나이·키·몸무게·체형·퍼스널컬러를 선택 저장할 수 있다. 실제 회원은 본인의 Auth user_metadata.body_profile에만 저장하며 공개 프로필에는 전달하지 않는다. 로컬 테스트 회원은 Git에서 제외된 별도 body-{계정}.json 파일에 소유자 전용 권한으로 저장한다. 공개 활동 데이터(activity.json)와 분리한다.

작성창의 ‘내 정보 불러오기’는 본인 인증 후 저장 정보를 읽는다. 불러온 직후 공개 체크는 모두 해제한다. 직접 선택한 항목만 게시글 body_spec으로 전달한다. 저장 정보 비우기는 기존 공개 글을 수정하지 않는다. 나이·키·몸무게는 기존 유효 범위 안의 정수 목록을 펼쳐 선택하는 드롭다운으로 표시한다.

신체 정보 입력 방식 변경: 나이·키·몸무게는 숫자를 직접 입력하며 단위를 옆에 표시하고, 체형은 자유 입력한다. 퍼스널컬러만 선택 목록을 제공한다. 작성창의 입력칸에 포커스하거나 값을 입력하면 해당 공개 체크가 켜지며, 값을 비우면 체크가 해제된다. 공개 체크를 직접 끄면 입력한 값은 유지하되 게시글에 전송하지 않는다. 비공개 저장 정보를 불러오는 동작 자체로는 체크하지 않는다.

체형도 선택형으로 변경했다. 균형·어깨·상체/하체 볼륨·골반·허리 굴곡·잘 모르겠어요 항목을 제공하며, 이전에 직접 입력한 값은 기존 정보 옵션으로 유지한다.

소올 원본 상품 복원: 소올 룸은 의류·뷰티·신발·잡화 12개씩 총 48개 상품을 유지한다. 가상 룸을 추가하거나 전문 취향별로 예시를 배치할 때 소올 원본 목록을 이동·축소하지 않는다. 로컬 복원 데이터는 기존 직접 작성 글과 가상 룸을 보존하며 별도 `soal-original-` 예시 ID를 사용한다. 큐레이션 상단 로고는 `/creators` 리다이렉트가 아닌 `/` 홈으로 직접 이동한다.
